## เส้นทางการอ่าน: อ่านตามลำดับนี้

แนะนำให้อ่านตามลำดับ ไม่ควรกระโดดไปท่องคำตอบสอบก่อนเข้าใจการไหลของข้อมูล

1. **[01 — ภาพรวมระบบและเส้นทางข้อมูล](docs/01-system-overview.md)**  
   เข้าใจก่อนว่าโปรแกรมทำอะไร มีขั้นตอนอะไรบ้าง ข้อมูลเริ่มจากไหนและจบที่ไหน

2. **[02 — คู่มือทำความเข้าใจไฟล์ทั้ง 4](docs/02-file-by-file.md)**  
   รู้หน้าที่ของ `main.py`, `data_analysis.py`, `simulation.py` และ `risk_report.py` รวมถึงหน้าที่ของฟังก์ชันหลัก

3. **[03 — พื้นฐาน Python และแนวคิดสำคัญ](docs/03-python-and-finance-basics.md)**  
   ทบทวนชนิดข้อมูล ตัวแปร list, dictionary, loop, condition, function, return, exception และแนวคิดทางการเงินที่ใช้ในโครงการ

4. **[05 — แผนที่ตำแหน่งโค้ดและฟังก์ชัน](docs/05-code-location-map.md)**  
   ใช้ค้นว่าฟังก์ชันหรือโค้ดแต่ละส่วนอยู่ไฟล์ไหน บรรทัดใด และหากต้องแก้ไขควรเริ่มจากจุดไหน

5. **อ่านโค้ดฉบับอธิบายภาษาไทยทั้ง 4 ไฟล์**  
   อ่านควบคู่กับคู่มือข้อ 2 โดยไล่จาก `main_thai.py` → `data_analysis_thai.py` → `simulation_thai.py` → `risk_report_thai.py`

6. **[04 — แนวข้อสอบปากเปล่าและ Live Coding](docs/04-oral-exam-practice.md)**  
   ใช้ทบทวนและทดสอบความเข้าใจหลังจากอ่านระบบและโค้ดแล้ว ไม่ใช่ใช้แทนการอ่านโค้ดจริง

## Checklist การเรียนรู้ของทีม

ทำเครื่องหมายเมื่อทำได้จริงโดยไม่เปิดเฉลยหรือให้ AI ตอบแทน หากยังทำไม่ได้ให้ย้อนกลับไปอ่านหัวข้อที่เกี่ยวข้อง

### ระยะที่ 1 — เข้าใจภาพรวม
- [ ] อธิบายได้ว่าโปรแกรมรับข้อมูลอะไรและสร้างผลลัพธ์อะไร
- [ ] วาดลำดับการทำงานตั้งแต่ผู้ใช้เริ่มโปรแกรมจนได้รายงานได้
- [ ] อธิบายได้ว่าแต่ละไฟล์มีหน้าที่อะไร
- [ ] อธิบายได้ว่าทำไมจึงแบ่งโปรแกรมออกเป็นหลายโมดูล

### ระยะที่ 2 — เข้าใจข้อมูลและการเชื่อมต่อ
- [ ] บอกได้ว่าฟังก์ชันหลักแต่ละตัวอยู่ไฟล์ไหน
- [ ] อธิบาย input, process และ output ของฟังก์ชันหลักได้
- [ ] ตามรอยได้ว่าฟังก์ชันใดเรียกฟังก์ชันใด
- [ ] อธิบายได้ว่าค่า return ถูกส่งไปเก็บหรือใช้ต่อที่ใด
- [ ] อธิบายโครงสร้าง list, dictionary และ list ซ้อน list ที่ใช้ในโครงการได้

### ระยะที่ 3 — เข้าใจโค้ด Python
- [ ] อ่านตัวแปร ชนิดข้อมูล และการแปลงชนิดข้อมูลได้
- [ ] อธิบาย if/elif/else และ for/while ได้
- [ ] อธิบาย function, parameter, argument และ return ได้
- [ ] อธิบาย try/except และเหตุผลของการตรวจสอบข้อมูลได้
- [ ] อธิบาย import และ if __name__ == "__main__" ได้

### ระยะที่ 4 — เข้าใจคณิตศาสตร์และการเงิน
- [ ] คำนวณ Daily Return ด้วยมือได้
- [ ] อธิบาย Mean, Variance และ Standard Deviation ได้
- [ ] อธิบาย Annualized Volatility และเหตุผลที่ใช้ sqrt(252) ได้
- [ ] อธิบาย Historical Bootstrap Monte Carlo และ seed ได้
- [ ] อธิบาย Probability of Loss, VaR และ Maximum Drawdown ได้

### ระยะที่ 5 — พร้อมสอบและแก้โค้ด
- [ ] เปิดตำแหน่งฟังก์ชันตามโจทย์ได้โดยใช้ Code Location Map
- [ ] อธิบายโค้ดหนึ่งฟังก์ชันโดยไม่อ่านคอมเมนต์ตามอย่างเดียวได้
- [ ] ทำนายได้ว่าการเปลี่ยน input หรือ parameter จะส่งผลอย่างไร
- [ ] อธิบายผลกระทบเมื่อเปลี่ยนชื่อฟังก์ชันหรือ dictionary key ได้
- [ ] ทำโจทย์ Live Coding พื้นฐานได้ด้วยตนเอง
- [ ] ตอบคำถามข้ามไฟล์ได้ ไม่จำกัดเฉพาะโมดูลที่รับผิดชอบ

**เกณฑ์ว่าเข้าใจจริง:** ไม่ใช่แค่จำคำจำกัดความได้ แต่ต้องอธิบายด้วยภาษาของตนเอง ยกตัวอย่าง input/output ได้ ชี้ตำแหน่งโค้ดได้ และบอกได้ว่าผลลัพธ์ถูกส่งไปใช้ต่อที่ไหน
